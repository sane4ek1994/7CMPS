Демонстрационный проект, на который можно ориентироваться: сам DevOps Campus.

## Что сделано

- Сайт собирается как статический экспорт Next.js. Каждый Markdown-файл из
  `cohorts/`, `topics/` и `projects/` превращается в отдельную HTML-страницу.
- GitHub Actions проверяют каждый pull request: линтер кода, линтер Markdown,
  проверка ссылок и сборка.
- После слияния в `main` Netlify пересобирает сайт и публикует папку `out/`.

## Что можно улучшить

- Добавить превью-деплои для pull request'ов и ссылку на них в комментарии.
- Проверять доступность страниц автоматически (например, axe или Lighthouse CI).
