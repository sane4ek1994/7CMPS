Какой сервис обычно слушает какой порт и по какому протоколу: веб и удалённый доступ,
сетевые службы, почта, файлы и VPN, базы данных и инструменты DevOps.

Номера ниже — порты **по умолчанию**. Любую программу можно настроить на другой порт,
поэтому на сервере проверяйте, кто что слушает на самом деле: `sudo ss -tulpn`.
Подробнее про порты, TCP и UDP — в материале
[«Сети: как запрос находит программу»](../../cohorts/07/net-practicum-2-prereading.md).

## Веб и удалённый доступ

| Порт | Протокол | Сервис | Заметка |
| --- | --- | --- | --- |
| 22 | TCP | SSH, SFTP, SCP | удалённый вход и передача файлов |
| 23 | TCP | Telnet | без шифрования, в продакшене не используют |
| 80 | TCP | HTTP | сайты без шифрования |
| 443 | TCP | HTTPS | сайты с TLS |
| 443 | UDP | HTTP/3 (QUIC) | новая версия HTTP поверх UDP |
| 3389 | TCP, UDP | RDP | удалённый рабочий стол Windows |
| 5900 | TCP | VNC | удалённый рабочий стол; следующий экран — 5901 и дальше |

## Диапазоны портов

| Диапазон | Название | Что значит |
| --- | --- | --- |
| 0–1023 | системные (well-known) | стандартные службы; в Linux занять такой порт может только root или программа с правом `CAP_NET_BIND_SERVICE` |
| 1024–49151 | зарегистрированные | закреплены за программами в реестре IANA, занять может любой пользователь |
| 49152–65535 | динамические | временные порты клиентов по IANA |

Linux по умолчанию берёт временные порты для исходящих подключений из своего диапазона,
32768–60999. Посмотреть его:

```bash
cat /proc/sys/net/ipv4/ip_local_port_range
```

## Как проверить

```bash
sudo ss -tulpn                  # кто на этом сервере слушает порты, TCP и UDP
nc -zv 203.0.113.25 5432        # открывается ли TCP-подключение к порту
grep -w 5432/tcp /etc/services  # как порт назван в справочнике системы
```
