Текстовая версия короткого доклада для созвона потока. Каждый раздел ниже
соответствует одному слайду.

## Слайд 1. Зачем вообще контейнеры

- «У меня работает» превращается в «работает везде, где есть рантайм контейнеров».
- Приложение едет вместе со своими зависимостями, но без целой виртуальной машины.
- Контейнер стартует за секунды, поэтому его легко пересоздать, а не чинить.

## Слайд 2. Образ и контейнер

| Образ | Контейнер |
| --- | --- |
| шаблон, только для чтения | запущенный экземпляр образа |
| собирается из Dockerfile | создаётся командой `docker run` |
| хранится в реестре | живёт на конкретной машине |

## Слайд 3. Запускаем

```bash
docker run --rm -d -p 8080:80 --name hello nginx:stable
curl -I http://localhost:8080
docker logs hello
docker stop hello
```

Флаг `--rm` удаляет контейнер после остановки: удобно для экспериментов.

## Слайд 4. Свой образ

```dockerfile
FROM nginx:stable
COPY site/ /usr/share/nginx/html/
```

```bash
docker build -t my-site:0.1 .
docker run --rm -p 8080:80 my-site:0.1
```
